# Asset sources

Asset provenance for the encounter. The multiplayer player avatars below are intentional placeholders.

## Audio — original, generated

All generated by [`tools/gen_audio.py`](../tools/gen_audio.py) (Python
standard library, fixed seed `1997`, deterministic). 16-bit PCM, mono,
44.1 kHz. Played non-spatially.

| File | Content | Use |
|---|---|---|
| `audio/whistle_loud.wav` | original ascending seven-step whistle phrase, dry and breathy | the whistle when he *seems* close (truly far) |
| `audio/whistle_mid.wav` | same phrase, low-passed, moderate reverb | seems somewhere across the grass |
| `audio/whistle_faint.wav` | same phrase, thin, high-passed, heavy reverb | seems far away (truly near) |
| `audio/ambience_llano.wav` | 24 s seamless loop: wind, grass hiss, crickets, distant frogs, a nightbird | night ambience (hushes during warning/hunt) |
| `audio/bones_rattle.wav` | synthesized bone clacks and burlap shuffle | taking the satchel |
| `audio/restitution.wav` | hollow root knock, soft open chord, breathy swell | bones returned |
| `audio/caught.wav` | rushing wind, low cluster, faint whistle fragment | caught |
| `audio/dawn.wav` | warm chord swell with soft bell partials | reaching the road |

Regenerate: `python3 tools/gen_audio.py` (writes into `assets/audio/`).

## Textures, meshes, lettering — original, generated at runtime

`src/world/texture.rs` builds every surface texture at startup from the seed
(tileable value noise, strokes, weave patterns): ground grass/soil, road
earth, weathered and dark wood, rusted corrugated zinc, ceiba bark, foliage,
burlap, straw, dark and pale cloth, clay, the note paper, the 1998 calendar page, the
"HATO LA CEIBA" sign (original 5×7 stencil glyphs) and the moon halo. All
geometry (house, fences, ceiba, props, grass, palms, sky, the Silbón) is built
procedurally in `src/world/`. No image or model files are shipped.

## Multiplayer player avatars — original placeholders

`src/net/mod.rs` builds amber and blue capsule/head meshes for remote players,
using existing satchel geometry for the carried item. These are deliberately
temporary, distinguishable player representations, not new environment or
enemy art. They add no cameras, lights or audio listeners.
